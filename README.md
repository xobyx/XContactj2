# XContactj2

[![CircleCI](https://circleci.com/gh/xobyx/XContactj2.svg?style=svg)](https://circleci.com/gh/xobyx/XContactj2)

XContactj2 is a contact manager application for Android. It provides a comprehensive suite of features to manage your contacts, calls, and messages.

## Key Features

*   **Contact Management:** Read, write, and manage your contacts.
*   **Call Management:** Access and manage call logs. Make phone calls directly from the app.
*   **SMS Management:** Read, write, and send SMS messages.
*   **Location Access:** Utilizes location data for relevant features.
*   **External Storage:** Reads from and writes to external storage for data management.
*   **Google Cloud Messaging (GCM):** Uses GCM for push notifications and other services.
*   **Analytics:** Integrates with Google Play Services Analytics and Firebase Analytics for usage insights.
*   **Crash Reporting:** Uses Fabric Crashlytics for robust crash reporting.

## Technologies Used

*   Java
*   Android SDK
*   Gradle
*   Google Play Services (Analytics, GCM)
*   Firebase Analytics
*   Fabric Crashlytics
*   OkHttp

## Building the Project

1.  Clone the repository: `git clone https://github.com/xobyx/XContactj2.git`
2.  Open the project in Android Studio.
3.  The project uses Gradle for building. Ensure you have the necessary Android SDK versions installed as specified in the `app/build.gradle` file.
4.  Build the project using Android Studio's build functionality or by running `./gradlew assembleDebug` (or `gradlew.bat assembleDebug` on Windows) in the project's root directory.
